# For Sanuhhhhh ❤️

A responsive birthday website made with plain HTML, CSS and JavaScript.

## Preview on your phone
1. Extract this ZIP file.
2. Open `index.html` in a browser, or upload the project to GitHub.
3. Keep the `assets` folder beside `index.html`, `style.css` and `script.js`.

## Publish free with GitHub Pages
1. Create a new public GitHub repository.
2. Upload **all four items**: `index.html`, `style.css`, `script.js`, and the `assets` folder.
3. In the repository, open **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**.
5. Choose `main` and `/ (root)`, then Save.
6. After GitHub finishes publishing, open the Pages link it provides.

## Add more memories
- Put extra photos in `assets`.
- Add another `<figure class="memory reveal">` in the gallery section of `index.html`, using the matching filename, alt text and caption.
- Add another `<article class="video-card reveal">` in the video section for each extra MP4.
- Use simple filenames such as `memory-09.jpg` and `video-03.mp4`.

## Notes
- The two uploaded videos are included as local MP4 files.
- The website does not autoplay audio. Visitors can choose to play videos.
- The letter is editable in `index.html`.
- Everything uses relative file paths, so it works on GitHub Pages.


## Background music
The website now has an opening screen and a music play/pause control.
For the music player to work, place an MP3 file that you own or are licensed
to use at `assets/background-music.mp3`. The opening button attempts to start
music after the visitor taps it; the visitor can pause or resume music anytime.
Do not publish commercial songs unless you have permission or the necessary rights.
